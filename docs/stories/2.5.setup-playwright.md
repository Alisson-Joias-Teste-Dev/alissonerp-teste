## Architect Notes (v1.1)

**Padrão de fixture de auth (recomendado):**

```typescript
// tests/e2e/helpers/auth.ts
import { test as base, Page } from '@playwright/test';

type TestRoles = 'admin' | 'gerente_loja' | 'consultora' | 'ourives' | 'pcp';

export const test = base.extend<{ loginAs: (role: TestRoles) => Promise<void> }>({
  loginAs: async ({ page }, use) => {
    await use(async (role) => {
      // Cookie injection é mais rápido que login via UI
      await page.context().addCookies([{
        name: 'sb-access-token',
        value: process.env[`CI_TOKEN_${role.toUpperCase()}`]!,
        domain: '.localhost',
        path: '/',
      }]);
    });
  },
});
```

**Tokens de teste:** gerados via Supabase Admin API com expiry longa (24h). Renovados em CI via secret.
