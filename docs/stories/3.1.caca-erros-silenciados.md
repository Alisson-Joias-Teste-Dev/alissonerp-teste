## Story

**As a** usuário operacional do ERP,
**I want** que toda falha de comunicação com o backend gere feedback visual claro (toast/banner) e que o frontend impossibilite introdução de novos `.catch(() => {})`,
**so that** falhas silenciosas que hoje aparentam "tudo ok" sejam imediatamente percebidas — resolve problema #8 do diagnóstico.

## Acceptance Criteria

1. **AC1:** `grep -rE "\.catch\(\(\) => \{\}\)|\.catch\(\(\) => null\)|\.catch\(\s*\(\) =>\s*$" src/` retorna **0 ocorrências** após esta story.
2. **AC2:** `src/lib/toast.ts` (ou equivalente) exporta `showError(message)`, `showSuccess(message)`, `showInfo(message)` com UI consistente.
3. **AC3:** `src/components/ErrorBoundary.tsx` global captura erros não tratados e mostra fallback amigável + botão "Recarregar".
4. **AC4:** ESLint custom rule `scripts/eslint-rules/no-empty-catch.js` bloqueia introdução de novos catches vazios. Lint falha CI.
5. **AC5:** Casos conhecidos refatorados:
   - `src/app/(dashboard)/vendas/nova/NovaVendaClient.tsx:280` — faixas de comissão
   - `src/app/(dashboard)/protocolo/ProtocoloClient.tsx:207` — concluídos
   - `src/app/(dashboard)/crediario/CrediarioClient.tsx` — sem catch visível em vários pontos
   - Outros descobertos via grep
6. **AC6:** Testes manuais validam: simular falha de rede em rota crítica → toast aparece com mensagem específica, não "Erro 500".
7. **AC7:** ErrorBoundary testada com erro deliberado em componente.
8. **AC8:** `npx tsc --noEmit` passa.

## Architect Notes (v1.1)

**Lib de toast recomendada:** `sonner` — minimal, sem dependências extras, integra bem com React 19. Alternativa: implementação própria com framer-motion (já instalado).

**ESLint rule custom estrutura:**
```javascript
// scripts/eslint-rules/no-empty-catch.js
module.exports = {
  meta: { type: 'problem', docs: { description: 'Disallow empty catch blocks' } },
  create(context) {
    return {
      CatchClause(node) {
        const body = node.body.body;
        if (body.length === 0) {
          context.report({ node, message: 'Empty catch block. Use toast or log error.' });
        }
        // Detectar `() => {}` em .catch()
        // ...
      }
    };
  }
};
```

**ErrorBoundary em React 19:** usar Class Component (não há hook equivalente). Alternativa: `<ErrorBoundary fallback={<Fallback />}>` da `react-error-boundary` (verificar se já está instalado — caso contrário, escrever próprio).

**ADRs aplicáveis:** nenhum direto (esta story é tactical).
