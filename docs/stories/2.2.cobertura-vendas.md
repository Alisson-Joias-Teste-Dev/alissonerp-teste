## Story

**As a** owner do ERP,
**I want** cobertura ≥ 80% no módulo Vendas (rotas + libs auxiliares),
**so that** mudanças futuras não introduzam regressão em fluxo de receita.

## Acceptance Criteria

1. **AC1:** `src/__tests__/api/vendas/route.test.ts` cobre POST (criar venda completa), PUT (editar), DELETE (cancelar) com cenários de sucesso e erro.
2. **AC2:** Cobertura `src/app/api/vendas/**` ≥ 80% (medido por `vitest --coverage`).
3. **AC3:** Cobertura `src/lib/validar-descontos.ts` ≥ 90%.
4. **AC4:** Testes cobrem cenários: cliente null, vendedor null, desconto > limite (consultora vs admin), pagamento múltiplo, vale-troca com troco, cancelamento com estorno, ordem de reposição falha (rollback).
5. **AC5:** Todos testes integration usam `withTestTx` (Story 2.1).
6. **AC6:** Coverage threshold no `vitest.config.ts`: `src/app/api/vendas/**` ≥ 80%, `src/lib/validar-descontos.ts` ≥ 90%.
7. **AC7:** CI (`ci-integration.yml`) roda os novos testes e bloqueia merge se cobertura cair.
8. **AC8:** `npx tsc --noEmit` passa.

## Architect Notes (v1.1)

**Adicional ao escopo (ponto cego 3.1):**

Cobrir **reservas de estoque comercial** — comportamento crítico:
- Inserir item de venda → cria **reserva** em `reservas_estoque_comercial` (NÃO saída)
- Aprovar venda → reserva vira saída em `movimentacoes_estoque_comercial`
- Cancelar venda em rascunho → reserva é deletada

**Test integration adicional:** `src/__tests__/integration/reservas-estoque-comercial.test.ts`
1. Criar venda com 3 itens → assert 3 reservas existem
2. Aprovar venda → assert 3 saídas em movimentacoes_estoque_comercial + 3 reservas removidas
3. Cancelar venda em rascunho → assert reservas removidas, sem saída

**Pegadinha CLAUDE.md §3:** `vw_saldo_estoque_comercial` precisa subtrair reservas do saldo disponível.

**Vale-troca cadeia (já mencionada):** `vale_origem_id` rastreia. Cada vale usado UMA vez. Test que valida cadeia: criar A, usar A em venda1 (gera vale B com troco), usar B em venda2 (consome). Assert `B.vale_origem_id = A.id`, `A.usado=true`, `B.usado=true`.
